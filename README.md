# novel-rnn-architectures

Experimental recurrent neural network architectures **PLUG and ILRM**, designed to improve long-range memory in sequential data while retaining relatively simple recurrent structures.

The repository includes mathematical framework papers, executable source code, GRU comparisons, long-memory experiments, and preliminary application-focused testing.

Potential areas of application include **robotics, autonomous systems, industrial automation, predictive maintenance, sensor-stream modelling, time-series forecasting, trajectory prediction, localisation during sensor dropout, and other sequential tasks where information from far earlier in a sequence may remain important**.
